# Deep Learning Roadmap 🧠

A comprehensive, interactive roadmap for learning all the key concepts in deep learning. This project provides both a traditional mind map visualization and a modern web application to track your learning journey.

## 🎯 Features

### Interactive Web App (`/client`)
- **Progress Tracking**: Mark topics as completed and track your overall progress
- **Hierarchical Structure**: Navigate through fundamentals to advanced topics
- **Modern UI**: Built with React, TypeScript, and TailwindCSS
- **Responsive Design**: Works beautifully on desktop and mobile
- **Dark Mode**: Easy on the eyes during late-night study sessions

### Mind Map Visualization (`index.html`)
- Traditional mind map view using Mind Elixir
- Drag-and-drop functionality
- Expandable/collapsible nodes
- Visual overview of the entire curriculum

## 📚 Curriculum Coverage

The roadmap covers five major areas:

1. **Fundamentals**
   - Linear Algebra (Matrices, Vectors, Eigenvalues)
   - Calculus (Derivatives, Gradients, Chain Rule)
   - Probability and Statistics

2. **Neural Networks**
   - Perceptron and basic architectures
   - Activation Functions (Sigmoid, ReLU, Tanh)
   - Backpropagation
   - Loss Functions (MSE, Cross-Entropy)

3. **Deep Learning Architectures**
   - CNNs (Convolutional Neural Networks)
   - RNNs (LSTM, GRU)
   - Transformers and Attention Mechanisms

4. **Training and Optimization**
   - Gradient Descent variants
   - Optimizers (Adam, RMSprop, Momentum)
   - Regularization techniques

5. **Applications**
   - Computer Vision (Classification, Detection, Segmentation)
   - Natural Language Processing
   - Reinforcement Learning

## 🚀 Getting Started

### Quick Start - Mind Map
Simply open `index.html` in your browser to view the interactive mind map.

### React Web Application

```bash
# Navigate to the client folder
cd client

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```

The app will be available at `http://localhost:5173`

## 🛠️ Technology Stack

### Web Application
- **Frontend**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **UI Components**: shadcn/ui
- **Routing**: React Router v6

### Mind Map
- **Library**: Mind Elixir
- **Vanilla JavaScript**: No build process required

## 📖 How to Use

1. **Start with Fundamentals**: Master the mathematical foundations before diving into neural networks

3. **Practice Coding**: Implement concepts from scratch before using frameworks
4. **Build Projects**: Apply what you learn to real-world problems
5. **Stay Current**: Keep updating your knowledge with latest research
